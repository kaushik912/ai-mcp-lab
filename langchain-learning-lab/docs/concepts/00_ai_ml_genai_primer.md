# AI / ML / DL / NLP / GenAI Primer

## Understanding AI and Related Terms

**Artificial Intelligence (AI)** — the broad field where machines perform tasks that typically require human-like intelligence.

**Machine Learning (ML)** — a subfield of AI where machines learn from data to make future predictions.

**Deep Learning (DL)** — a further subfield within ML that mimics the human brain using neural networks. Common applications: object recognition, language translation, speech processing.

**Natural Language Processing (NLP)** — enables machines to understand and process human language, both text and speech. This advancement paved the way for Generative AI (GenAI).

## Traditional Machine Learning Workflow

1. **Data Collection** — gather relevant datasets.
2. **Data Preparation** — clean and remove junk data.
3. **Split the Data** — 80% training, 20% testing.
4. **Select an Algorithm** — choose one that fits the problem type.
5. **Train the Model** — teach it using the training data.
6. **Test the Model** — validate accuracy with the testing data.
7. **Tune & Deploy** — optimize for performance and push to production.

## Generative AI vs Traditional ML

| Traditional ML | Generative AI |
|---|---|
| Predicts outcomes based on data | Generates new content (text, images, code, etc.) |
| Example: predicting housing prices | Example: writing an article, creating an image |

OpenAI's GPT model (Generative Pre-trained Transformer) is a leading example of Generative AI.

## Open Source LLMs

Examples: Llama (Meta), Gemma (Google), Mistral. These can run locally on your own machine and don't require an API key.

|---|---|---|

| Gemma – 2B | 2B | ~2 GB |
| Mistral – 7B | 7B | ~8 GB |
| 13B models | 13B | ~16 GB |
